## Fase 5.6: GT sim port (movement, speed, rules)

New package `scripts/gt/` (core `scripts/core/*` untouched, Pit Wall session and its tests keep the old engine):

| File | Port of | Content |
|---|---|---|
| `gt_types.gd` | `types.ts` | enums (compound S/M/H/I/W, pace 5, fuel 3, ERS 4, tactic 3, flag), constants |
| `gt_rng.gd` | `rng.ts` | mulberry32, same seed = same race |
| `gt_track.gd` | `track.ts` | built from `TrackRibbon`: curvature, ideal line `d_target`, speed profile (lateral accel, forward/backward pass), DRS zones, width clamp, pit lane parameters |
| `gt_car.gd` | `CarState` | continuous `s`, `lateral`, `v`, `v_lat`, steer / roll / pitch / yaw, tyres, fuel, ERS, DRS, damage, telemetry |
| `gt_data.gd` | `teams.ts` | 10 La Voiture teams x 2 drivers with the reference stats (own names, no real brands) |
| `gt_weather.gd` | `buildWeatherProfile`, `updateWeather` | 7 archetypes, rain, water %, drying line, temps, time of day |
| `gt_race.gd` (+ helpers) | `race.ts` | tick, AI overtake / defend / yield / side-by-side breaker, collision resolver, DRS, ERS, slipstream, fuel stages, tyre cliff + puncture, incidents, flags + safety car, pit lane + queue, strategy, hybrid tactic cards, standings, sectors, speed trap |

Differences from the reference, all deliberate:
- Track is the 3D ribbon (4159 m, road widened to 14 m for the weekend world); the sim runs directly on it, no distance scale.
- Fixed tick 0.05 s (20 Hz, the reference rate); render interpolates between ticks; 1x..16x run the same tick sequence.
- Pit lane uses the Fase 5.5 geometry (`PitLaneComplex`: entry s 3900, exit s 150 after the line, stalls s = 3925 + 14 x team, right side, +15.5 m) instead of the reference chute; limiter 22.2 m/s, stop 3.2 s (+ damage repair).
- Speed targets: V_MAX 80 m/s, lateral accel 21 m/s2, braking 15, accel 6.8; target lap 85-95 s on 4159 m.
- Cars/teams use La Voiture names (`RaceSimEngine.TEAM_NAMES`, `DRIVER_NAMES`).

Acceptance (tests/test_gt_sim.gd): plausible lap times; determinism by seed; no NaN; pit stop gives fresh tyres, one stop; collision separation; DNF sorting; SC/VSC speed caps and flag hierarchy; side-by-side breaker; one-move defending and racing room; blue flag; DRS/ERS/slipstream; fuel stages; tyre cliff and puncture; weather archetypes; chassis angles finite; 20-car lap with 0 overlapping boxes; lane use is continuous (no 3-abreast stacks lasting > 2 s).

## Fase 5.7: dynamics and VFX

- Front wheels steer (`socket.rotation.y = steer_angle`, caliper turns with the knuckle), rear wheels only roll; sasis roll / pitch / yaw from the sim (`roll = a_c x 0.0022` clamp 0.085, `pitch = -a_long x 0.0026`, steer = `kappa x 14 + heading x 1.35` clamp 0.42).
- Brake glow already present. Headlights at night. *Revised after owner review:* the DRS wing flap and tail light bar were removed (they read as floating red / blue bars); DRS, PIT, HAZARD and BRAKE show as small graffiti stickers on a billboard tip over the car, and the driver code is a graffiti slab that only flashes up for a moment (pass, selection, rival within 60 m) at 0.6 opacity. Body roll, pitch, yaw and steer are eased in the actor (two cascaded low-passes, 0.07 s) so the 20 Hz sim steps do not twitch.
- VFX assembled in the weekend world: rain + road spray + wet shader (weather), tyre smoke (start, lock-up, spin), contact / pit-gun sparks, slipstream ribbons, exhaust pops, overtake accent.

## Fase 5.8: fused HUD

One La Voiture overlay (toon / manga / acid lime, existing `UIThemeTokens` + `PitWallUI`): timing tower (GAP / SECTOR tabs, tyre pills, DRS badge), circuit radar + speed trap, radio cut-in with Accept / Dismiss tactic cards (hybrid mode), tactical deck (pace 5, fuel mix 3, ERS 4, pit + tyre choice, collapsible with `M`), telemetry drawer (`T`: speed, gear, pedals, G, 4-wheel matrix, fuel stages, driver biometrics), weather widget, flag banner. Fed by `GtRace` snapshots; Pit Wall dashboard widgets are reused through adapters.

*Revised after owner review:* the tactical deck is one full-width strip (1888 x 140 px, layout A) under the tower and the telemetry drawer so no bottom corner stays empty; the telemetry drawer is instruments (shift lights, speed bar, pedal trace, G box, tyre heat matrix, fuel vs flag, ERS meter, stress / confidence bar, heartbeat) with only gear, speed, fuel margin and heart rate as numbers; the pit close-up camera shows only the selected car; a clicked tower row gives up keyboard focus when another car is selected.
